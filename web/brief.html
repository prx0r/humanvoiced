Tell the narrator what you need.

A good brief should be obvious at a glance. Start with the words, then add the context a human needs to deliver the right performance.

What are we recording?

The script is the source of truth. Lock it once the narrator accepts the job.

02

Direction, not micromanagement

Tell them how it should feel and what it is for. Only add scene notes when something really changes.

03

Does the narrator need the video?

Most narration jobs only need the script. Add picture reference when exact timing or reacting to visuals matters.

Production should use permissioned storage with expiring links. Never make private pre-release videos public.
